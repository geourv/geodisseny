# Configurar coordenades mitjanes a QGIS

Captura en català per a estudiants de grau de Geografia. Mostrar el diàleg real
de `native:meancoordinates` amb la capa Quatre punts ficticis carregada,
`POT_KW` com a pes i sense camp d'agrupació. Explicar visualment la diferència
entre escollir un pes i escollir un grup, sense tapar els valors del formulari.
Les dades provenen exclusivament de l'exemple sintètic del capítol 4.
La captura mostra configuració; la comprovació numèrica es desenvolupa al text.
