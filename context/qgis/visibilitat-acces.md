# Localitzar les eines de visibilitat i de geometria

Vull mostrar com un estudiant arriba a les eines abans de configurar-les.
Amb les dades del cas del Polígon Sud carregades, obre el menú Procés i
assenyala la caixa d'eines amb un requadre. Després mostra el botó de la barra
amb un requadre i obre realment el panell. Desplega GDAL → Miscel·lània ràster
i selecciona Viewshed; la captura ha de mostrar el grup i l'eina, no només
l'accés. Mostra també Vectorial → Geoprocessing Tools → Àrea d'influència
amb els menús desplegats, i Geometria vectorial → Àrea d'influència dins de
la caixa. Requadra botons i files sense tapar-ne el text. La interfície
ha de ser la de QGIS3.44 en català, amb els noms i traduccions disponibles.

Utilitza les dades de visibilitat-costa-20261002-r3, el runtime fixat i
selectors de widgets/accions. La captura ha de mostrar què triar o prémer;
els diàlegs de paràmetres continuen a la recepta visibilitat-costa.
Mantén visibles els noms de les eines i els proveïdors.
