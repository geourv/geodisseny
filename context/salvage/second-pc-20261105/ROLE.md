# Fonts de recuperació per al segon PC

**DRAFT DE TRASPÀS. Material històric o de treball, no codi canònic ni contingut web aprovat.**

Aquest conjunt conserva 40 fonts autorades, 453.474 bytes: 32 versions històriques
úniques de l'stash `127c2256d2aea5dd2c05d6595a1c33471ffa3400` (420.268 bytes) i
8 fonts locals de disseny, proves i orquestració (33.206 bytes). Els onze originals
actuals ja són al commit `7b1c4fcd3e21062c7be19e322a000170cf9b0ba0`, PR #25.

`MANIFEST.json` relaciona cada còpia amb el path original, SHA256, mida, mode físic,
blob Git i ref/commit d'origen quan existeixen. Els 16 membres restants de l'stash
estan coberts amb blobs exactes per la història pública de main i s'hi documenten.
Cap original, stash o recuperació anterior s'ha eliminat ni substituït.

Les còpies tenen sufix `.source` per impedir-ne l'execució o descoberta accidental.
En particular, `AGENTS.md.source` és text històric, no instruccions actives. Els
prefixos `local-cache` i `local-sandbox` identifiquen els paths locals d'origen sense
fer servir directoris que les regles d'ignore exclourien de Git. No cal editar cap
configuració del lloc: `context/` ja està exclòs de Jekyll.

Les afirmacions d'aprovació, versions, límits i estat que hi ha dins de les còpies
són les del moment històric. Aquesta preservació no les revalida ni atorga
aprovació editorial/funcional. Els guions poden contenir paths locals, guards de
HEAD o operacions create-only: no executar-los a cegues des d'aquest arxiu.

Tots els continguts s'han revisat com a fonts UTF8 de docència/procediment. No s'hi
han detectat credencials, treballs d'estudiants ni registres de qualificació.
Es mantenen els avisos, drets i atribucions existents; l'autor autoritza aquesta
preservació. No s'atorga una nova llicència ni s'inclouen dades o codi de proveïdor.

Git conserva bytes i el bit executable, no tots els permisos POSIX. El manifest
reté els modes originals: 0644 de les còpies històriques i 0664 de les fonts locals.
Les còpies físiques preserven aquests modes; els blobs regulars són mode100644.

Les dades/pràctiques i les captures no cobertes per Git necessiten el seu canal
privat de dades. El manifest machine-readable complet és al dossier ignorat de
l'owner `.cache/geo2-20261104-01/salvage-resources-20261105-01/`. No es declara
reproduïble al destí cap producte amb fonts/inputs/projectes/versions inaccessibles.
No s'ha renderitzat, calculat, desplegat ni canviat cap selecció de runtime.
